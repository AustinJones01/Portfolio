# Frontend Web Application
A clean, responsive frontend web application built using semantic HTML. This project is structured as a clean demonstration of production-ready semantic layout and accessibility practices.

## Live Demo
[View the Live Website] https://github.com/AustinJones01/Portfolio

## Technical features
* **Semantic HTML5:** Built using meaningful structural elements to ensure strong SEO and accessibility baselines.
* **Responsive Layout:** Designed to scale dynamically across desktop, tablet, and mobile displays.
* **Zero Dependencies:** Pure, lightweight frontend architecture with no external bloat or build steps.
